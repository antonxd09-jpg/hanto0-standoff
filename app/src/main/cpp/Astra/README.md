# KRIWARE

KRIWARE — нативная модификация Standoff 2 для Android с внутриигровым меню на Dear ImGui. Проект написан на C++17 и рассчитан на конкретный ARM64-бинарник игры версии 1.1.0. Меню открывается и закрывается нажатием на ватермарк KRIWARE.

## Возможности

| Вкладка | Что в ней |
| --- | --- |
| **Visuals** | ESP с рамками, здоровьем, бронёй и данными об оружии. Настройки оформления, предпросмотр, тест камеры от третьего лица, Hitlog, Hitsound и GPU Night Mode. |
| **Silent** | Настройки выбора цели, угла обзора, дальности, хитбоксов, проверки видимости и предсказания. |
| **Config** | Статус профиля игры, камеры и хуков, счётчики ESP и синхронизации Silent, сохранение диагностического лога. |

В версии **Sync V2** команда выстрела и обработчик лучей используют одну выбранную точку. Привязка к номеру команды предотвращает повторное применение угла от предыдущего выстрела при переиспользовании объекта команды. Счётчики в Config показывают работу клиента. Подтверждение серверного урона требует проверки в игре.

## Сборка

Нужен Android NDK с `ndk-build` в `PATH`. Конфигурация проекта задаёт ABI `arm64-v8a` и минимальный Android API 23. Dear ImGui и ARM64-библиотека Dobby входят в архив.

Распакуйте архив и запустите команду из каталога `Astra/`, где находится папка `jni/`:

```sh
ndk-build NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=jni/Android.mk NDK_APPLICATION_MK=jni/Application.mk
```

Ожидаемый результат сборки — `libs/arm64-v8a/libastra.so`. В архиве исходников этой библиотеки нет. Входящий в архив `build.sh` ссылается на отсутствующий `scripts/build.sh`, поэтому используйте команду выше.

## Проверки

Для проверок на компьютере нужны Python 3 и `g++`. Первые две команды проверяют меню и регрессию синхронизации Silent. Для последних двух нужен соответствующий дамп версии 1.1.0.

```sh
python3 checks/verify_gui.py
python3 checks/verify_silent_sync.py
python3 checks/verify_offsets_110.py /path/to/1.1.0/dump
python3 checks/verify_silent_110.py /path/to/1.1.0/dump
```

Оффсеты и сигнатуры привязаны к GNU Build ID `69815f2befe135c2`. При диагностике сначала проверьте **Config → Binary profile**, затем сохраните отчёт через **Save silent diagnostics**. Поле `sync` показывает совпадения плана с командой и причины отказов, включая устаревшую команду, смещение цели и неподтверждённую запись угла.

## Структура

| Путь | Назначение |
| --- | --- |
| `jni/src/core/entry.cpp` | Точка входа и подключение интерфейса. |
| `jni/src/ui/kazakh/menu.hpp` | Меню, вкладки и ватермарк KRIWARE. |
| `jni/src/features/visuals/` | ESP, камера и визуальные эффекты. |
| `jni/src/features/aim/` | Логика Silent, профиль адресов и диагностика. |
| `jni/src/game/` | Профиль игры и работа с метаданными IL2CPP. |
| `checks/` | Проверки и материалы переноса на 1.1.0. |

Android-сборка текущего архива и регистрация урона после Sync V2 ещё требуют проверки на устройстве. Обычный Aim, Anti-Aim и управление отдачей не входят в активный интерфейс этой версии.
