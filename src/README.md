# Durow — только интерфейс меню

Окно, вкладки, переключатели, ползунки, поиск, пресеты, шрифты, изображения
и редактор предпросмотра. Переключатели меняют только локальные значения UI.
Игровых модулей, чтения/записи памяти игры, инжектора, загрузчика,
host_bridge, integration и HostState в пакете нет.

Сборка (Visual Studio 2022 с C++, CMake):

    cmake -S . -B build -G "Visual Studio 17 2022" -A x64
    cmake --build build --config Release --parallel 4
    ctest --test-dir build -C Release --output-on-failure

Цель durow_menu — библиотека интерфейса. menu_smoke — проверка отрисовки
в память, без открытия окна. Для вывода на экран подключите библиотеку
к своему приложению с ImGui-бэкендом. Используйте ту версию ImGui,
которая лежит в third_party/imgui.

После создания ImGui-контекста вызовите nl::load_fonts(), menu.init(...)
и menu.set_visible(true). Каждый кадр между ImGui::NewFrame() и
ImGui::Render() вызывайте menu.render(). Перед уничтожением контекста
вызовите menu.shutdown(). Ресурсы assets должны оставаться доступны.

Поля с названиями Aim, ESP, Skins и т. п. — элементы интерфейса,
а не реализация этих функций. Старые пресеты чита не совместимы.
Изменения сделаны только в экспортированной копии.
